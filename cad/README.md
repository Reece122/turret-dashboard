# CAD

Turret mount / enclosure design files. Drop both the native project file and
an exported STL here, then update the table in the root `README.md` with the
real filenames.

- **Native file** (Fusion 360 `.f3d`, SolidWorks `.sldprt`/`.sldasm`, etc.) —
  full parametric history, only openable in that tool.
- **STL** — print-ready mesh, viewable anywhere (including GitHub's built-in
  3D file viewer when committed directly).
